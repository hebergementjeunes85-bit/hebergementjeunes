# Site hebergementjeunes.fr – mise en ligne (gratuite)

## 1. Mettre les fichiers en ligne (une seule fois)
1. Crée un compte gratuit sur https://github.com
2. Crée un dépôt (bouton « New »), nom : `hebergementjeunes`, en **Public**.
3. Clique « uploading an existing file » et glisse tout le contenu du dossier décompressé (y compris `.pages.yml`), puis « Commit changes ».
4. Dépôt > **Settings > Pages** > Source : « Deploy from a branch », branche `main`, dossier `/ (root)` > Save.
5. Toujours dans Pages, champ **Custom domain** : `hebergementjeunes.fr`. Chez ton registrar (là où tu as acheté le nom de domaine), ajoute les enregistrements DNS indiqués par GitHub. Coche « Enforce HTTPS ».

## 2. Gérer les annonces (au quotidien)
1. Va sur https://app.pagescms.org et connecte-toi avec GitHub, choisis le dépôt.
2. **Annonces** : ajoute un logement, modifie le texte, glisse les photos, décoche « Disponible » quand c'est loué, ou supprime l'annonce. Clique « Save ».
3. **Infos de contact** : change ton téléphone, ton email, le texte d'introduction.
Le site se met à jour tout seul en 1 à 2 minutes.

Conseil photos : réduis-les avant (≈ 1600 px de large, moins de 500 Ko) pour que le site reste rapide.
